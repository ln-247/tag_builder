# Tag Builder

Tag Builder — приложение для подготовки и обработки таблиц тегов для систем управления.
Проект реализован с разделением на frontend и backend:
* frontend: Streamlit-интерфейс для загрузки файлов, выбора параметров обработки, предпросмотра результата и скачивания итоговой таблицы
* backend: FastAPI-приложение для обработки API-запросов, сохранения обратной связи и работы с базой данных
* database: SQLite для хранения сообщений обратной связи

## Основные возможности

Приложение позволяет:
* загружать таблицы тегов в форматах CSV, XLSX, XLS, ODS
* приводить таблицы к единому шаблону колонок
* нормализовать имена тегов
* добавлять суффикс `_PV`
* добавлять префикс к тегам, начинающимся с цифры
* нормализовать единицы измерения
* добавлять дополнительные теги для поломок
* добавлять MV, SV, MODE для регуляторов
* выставлять логирование для нужных типов тегов
* обрабатывать `project.db` и выгружать данные из таблицы `tags`
* отправлять обратную связь через frontend
* сохранять обратную связь в SQLite через FastAPI
* просматривать сохранённые сообщения обратной связи в интерфейсе Streamlit

### Frontend
Frontend реализован на Streamlit.
Он отвечает за пользовательский интерфейс: загрузку файлов, выбор параметров обработки, отображение результата и скачивание итогового CSV-файла.

Вкладки приложения:
1. **Предобработка таблицы** — подготовка исходной таблицы к дальнейшей обработке.
2. **Tag Builder** — основная обработка тегов.
3. **Работа с project.db** — загрузка и обработка данных из базы проекта.
4. **Обновления и обратная связь** — отправка и просмотр сообщений обратной связи.

### Backend
Backend реализован на FastAPI.
Он отвечает за API-запросы, связанные с обратной связью и базой данных.

Реализованные endpoints:
```text
GET /health
```
Проверка, что backend запущен.

```text
POST /feedback
```
Сохранение нового сообщения обратной связи в SQLite.

```text
GET /feedback
```
Получение списка сохранённых сообщений обратной связи.

### Database
Для хранения обратной связи используется SQLite.
База данных создаётся автоматически при запуске backend, если её ещё нет.

Таблица `feedback` хранит:
* id сообщения
* дату и время создания
* имя пользователя
* имя проекта
* систему управления
* текст сообщения

## Запуск backend
Backend запускается отдельно через Uvicorn.
```bash
uvicorn backend.api:app --reload
```

После запуска backend будет доступен по адресу:
```text
http://127.0.0.1:8000
```

Проверка работы backend:
```text
http://127.0.0.1:8000/health
```

Документация FastAPI:
```text
http://127.0.0.1:8000/docs
```

## Запуск frontend
Frontend запускается отдельно через Streamlit.
```bash
streamlit run frontend/main.py
```

## Что реализовано в рамках проекта
В проекте реализована рекомендуемая связка Streamlit + FastAPI.

Streamlit используется как frontend для интерактивной работы с таблицами.
FastAPI используется как backend для приёма и выдачи данных обратной связи.
SQLite используется для хранения сообщений обратной связи.

Основная обработка таблиц реализована в отдельном модуле `processing.py`.
